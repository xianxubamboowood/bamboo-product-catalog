# Fill out a request for quotation

Download `rfq-template.csv` for a new request, or open `rfq-example.csv` to see a fictional buyer brief. The sample quantities, dimensions and finishes are buyer requests. A supplier must confirm what it can supply and at what price.

1. Open the template in Excel or Google Sheets. If it opens as a single column, import it as UTF-8 text with a comma delimiter. Widen the columns or turn on text wrapping.
2. Use one copy per item or design. Fill in **Buyer entry** and leave **Field** and **Guidance** in place. Describe the product even if you have not chosen a catalog model. You can add a model code and the source page in **Catalog model (optional)** later.
3. Before sending the CSV to a supplier, check the units, quantity, destination and sample request. Save as CSV UTF-8 and share the completed copy privately with the supplier.
